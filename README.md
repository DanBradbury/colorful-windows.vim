# colorful-windows.vim

Configurable window separator to make the active window more distinguishable. This plugin will color surround the active buffer in a colorful border, similar to what tmux does for different panes.
</div>


## Requirements
- vim 9.0+

## Installation
Use your plugin manager of choice to install

## Configuration

```
g:colorful_windows_border_color = 'blue'
```
